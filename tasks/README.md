# Task 작업 공간

선택한 workflow에서 사용하는 active 계획·실행 증거를 보관합니다. 기본 실행 상태의 단일 근거는 .forgeflow/workflows/<id>.json이며 중복 승인 장부를 만들지 않고 참조합니다.

tasks/completed/와 과거 docs/releases/는 불변 evidence입니다. 현행 지침을 대체하거나 정책 이전을 꾸미기 위해 수정하지 않습니다. Active task의 요구사항은 해당 task에 적용됩니다.

현행 workflow 규칙은 docs/spec/, 저장소 지침은 AGENTS.md가 소유합니다. Strict package 완료는 Git 통합·정리 완료를 뜻하지 않습니다.
